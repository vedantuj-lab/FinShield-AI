2. **Clear Cache**: F12 → Storage → Clear All → Refresh
3. **Private Window**: Open private/incognito window and try again
4. **Different Browser**: Try Chrome, Firefox, or Edge
5. **Check Console**: Press F12 → Console tab for errors
